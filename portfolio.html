About Coding

HTML

HTML (HyperText Markup Language) is the standard markup language used to create the structure and content of web pages. It was created by Sir Tim Berners-Lee at CERN in the early 1990s as a way for researchers to share and link documents HTML acts as the "skeleton" of a website, defining where headings, paragraphs, images, and other elements appear.

CSS

CSS (Cascading Style Sheets) is a cornerstone technology of the World Wide Web used to describe the presentation and styling of documents written in markup languages like HTML. While HTML provides the "skeleton" or structure of a page, CSS acts as the "skin," controlling visual aspects such as layout, colors, and fonts

BOOTSTRAP

Bootstrap is the world’s most popular free and open-source frontend framework used to build responsive, mobile-first websites. Originally developed at Twitter in 2010 (as "Twitter Blueprint") to standardize internal tools, it was released to the public in 2011

UI/UX

UI/UX design focuses on creating intuitive, visually appealing, and functional digital products. UI (User Interface) refers to the look, feel, and interactivity (colors, buttons, layout), while UX (User Experience) covers the overall, seamless experience and functionality a user has with a product. Together, they ensure products are both aesthetically pleasing and easy to use.

SCRATCH

Scratch is a free, block-based visual programming language and online community designed primarily for ages 8 to 16 to create interactive games, stories, and animations. Developed by the MIT Media Lab, it promotes computational thinking and creative learning by snapping together code blocks, making it accessible for beginners.
